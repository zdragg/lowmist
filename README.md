# lowmist

_Lowmist_ is a Minecraft painting by Kristoffer Zetterstrand:

![Lowmist by Kristoffer Zetterstrand](https://zetterstrand.com/eventz/wp-content/uploads/LowMist-1.jpg)

_Lowmist_ is also a schematic renderer that tries to be as cool as the painting.

## Usage

This crate relies on nightly features.

Install bleeding edge [Bevy CLI](https://github.com/TheBevyFlock/bevy_cli):

```sh
cargo install --git https://github.com/TheBevyFlock/bevy_cli --branch main --locked bevy_cli
```

Run native:

```sh
bevy run
bevy run --release
```

Run on the web:

```sh
bevy run web
bevy run --release web
```
